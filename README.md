# 🏡 PadosiPro - Full-Stack Neighborhood Lifestyle Management App

**PadosiPro** is a neighborhood lifestyle management service application built as a full-stack monorepo. It empowers users to register, verify their email address via a secure 6-digit OTP, configure their household or business profile, choose tasks/services they need or offer, and manage active service selections through an intuitive home dashboard.


## 🛠️ Project Setup & Infrastructure

### 1. Start Infrastructure Services (PostgreSQL & Mailpit)

From the project root directory, launch PostgreSQL and Mailpit via Docker Compose:

```bash
docker compose up -d
```

#### Service URLs & Credentials:
- **PostgreSQL Database**: `localhost:5432`
  - Database Name: `padosipro_db`
  - Username: `padosi_user`
  - Password: `padosi_password`
- **Mailpit Web UI (Email Catcher)**: [http://localhost:8025](http://localhost:8025)
  - Inspect 6-digit OTP verification emails generated by the backend.
- **Mailpit SMTP Server**: `localhost:1025`

## ⚙️ Environment Configuration

### Backend Environment (`backend/.env`)

Create `backend/.env` (or copy from `backend/.env.example` if available):

```env
PORT=4000
NODE_ENV=development

DATABASE_URL=postgresql://padosi_user:padosi_password@localhost:5432/padosipro_db

SMTP_HOST=localhost
SMTP_PORT=1025
SMTP_SECURE=false
EMAIL_FROM="PadosiPro <no-reply@padosipro.com>"

JWT_SECRET=super_secret_jwt_key_change_in_production
JWT_EXPIRES_IN=7d
OTP_EXPIRY_MINUTES=10
OTP_MAX_ATTEMPTS=5
OTP_RESEND_COOLDOWN_SECONDS=30
```

### Mobile API Host Configuration (`mobile/src/config/env.ts`)

The mobile client automatically detects the platform API host:
- **Android Emulator**: Resolves to `http://10.0.2.2:4000/api`
- **iOS Simulator / Web**: Resolves to `http://localhost:4000/api`
- **Physical Device (Expo Go)**: Update `mobile/src/config/env.ts` with your computer's local Wi-Fi IP address (e.g. `http://192.168.1.5:4000/api`).

## 🚀 Step-by-Step Running Guide

### Quick Start (Using Monorepo Root Commands)

```bash
# 1. Start Docker containers
npm run docker:up

# 2. Run Backend API server (in one terminal tab)
npm run backend:dev

# 3. Run Mobile Expo server (in another terminal tab)
npm run mobile:start
```

---

### Manual Step-by-Step Instructions

#### Step A: Backend Startup

1. Open a terminal and navigate to the `backend` directory:
   ```bash
   cd backend
   npm install
   ```

2. Initialize the database schema and seed catalogue data:
   ```bash
   npm run db:init
   ```

3. Start the backend development server with hot-reload:
   ```bash
   npm run dev
   ```
   *The Express server runs at `http://localhost:4000`.*  
   *Verify API health: `curl http://localhost:4000/health`*

#### Step B: Mobile App Startup

1. Open a second terminal and navigate to the `mobile` directory:
   ```bash
   cd mobile
   npm install
   ```

2. Start the Expo development server:
   ```bash
   npm start
   ```

3. Launch the app on your preferred target:
   - Press **`a`** to open on a connected **Android Emulator**.
   - Press **`i`** to open on an **iOS Simulator**.
   - Scan the displayed QR code with the **Expo Go** app on your physical mobile device.

## 📦 Building Standalone Android APK

You can build a standalone Android APK file for distribution using either Expo EAS Build or local Gradle.

### Method 1: EAS Build (Recommended for Expo Monorepos)

1. Install EAS CLI and log into your Expo account:
   ```bash
   npm install -g eas-cli
   eas login
   ```

2. Build the Android preview APK from the root or `mobile` directory:
   ```bash
   npm run mobile:build:apk
   # OR
   cd mobile && npx eas-cli build --platform android --profile preview
   ```

### Method 2: Local Standalone Android Build

If Android Studio, Android SDK, and NDK are installed on your machine:

```bash
cd mobile
npx expo run:android --variant release
```

## 🔄 Complete App User Journey Walkthrough

Test the complete end-to-end workflow on mobile:

1. **Register**:
   - Launch the app. On the **Sign In** screen, tap **Register**.
   - Enter `Email` (e.g. `user@example.com`), `Password`, and `Confirm Password`.
   - Tap **Register & Continue**.

2. **Email Verification (OTP)**:
   - You are navigated to the **OTP Verification** screen.
   - Open Mailpit Web UI in your browser at [http://localhost:8025](http://localhost:8025).
   - Find the OTP email sent to `user@example.com` and copy the 6-digit code.
   - Enter the code in the app and tap **Verify OTP Code**.

3. **Sign In**:
   - Upon successful OTP verification, you are redirected to **Sign In** with your email pre-filled and a green verification success notice.
   - Enter your password and tap **Sign In**.

4. **Profile Setup**:
   - As a first-time user, you land on the **Complete Your Profile** screen.
   - Enter Full Name, Indian Mobile Number (`+919876543210`), Residential Address, and optional Business Name.
   - Tap **Save Profile & Continue**.

5. **Task Selection**:
   - Next, the **Select Your Services** screen opens.
   - Filter by category tabs (*Home & Maintenance*, *Errands*, *Senior Care*, *Admin*) or search for services.
   - Select tasks (e.g. *Plumbing Repair*, *Grocery Drop-off*) and tap **Save Selected Tasks**.

6. **Home Dashboard**:
   - You land on the authenticated **Home Screen** displaying your selected active services, category badges, account details, and quick status metrics.

7. **Profile Management & Re-entry**:
   - Access **Profile** from the home screen to update personal info anytime.
   - Tap **Log Out** in the header. Upon signing in again as a verified user with a complete profile, you are routed **directly to the Home Screen**!
